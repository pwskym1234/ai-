# 커머스 실연동 준비 문서

## 목표
쿠팡, 오아시스 같은 외부 커머스와 장바구니/결제를 정식으로 연결하려면 우회 구현이 아니라 파트너십과 공식 API가 필요하다.

## 필요한 단계
1. 제휴/파트너십 확인
- 오픈 API, 어필리에이트, 파트너 센터, 제휴 계약 가능 여부를 먼저 확인한다.
- 장바구니/주문 API는 일반 공개가 아닌 경우가 많아 계약 범위를 명확히 해야 한다.

2. 상품 카탈로그와 매핑
- ingredientName을 실제 SKU에 연결할 상품 검색 API 또는 카탈로그 API가 필요하다.
- 동일 재료의 용량/브랜드/카테고리 규칙을 정의하고 품절 대체 전략도 함께 설계한다.

3. 사용자 인증
- 사용자 계정과 스토어 계정을 연결하려면 OAuth, SSO, 또는 리다이렉트 기반 인증 절차가 필요하다.
- 자체 서비스에서 민감한 로그인 정보를 직접 수집/보관하지 않도록 구조를 나눠야 한다.

4. 장바구니 API
- 장바구니 추가/삭제/수량변경 API가 제공되는지 확인한다.
- 카트 세션 만료, 계정별 상태, 디바이스 간 동기화 정책도 함께 확인한다.

5. 결제/체크아웃 흐름
- 결제는 리다이렉트, 앱 딥링크, 웹뷰 허용 정책 중 어떤 방식이 가능한지 검토한다.
- 결제 완료 콜백이나 주문 상태 확인 API가 있어야 후속 UX를 설계할 수 있다.

6. 보안/개인정보/약관 준수
- 토큰 저장 위치, 만료/갱신, 암호화, 민감정보 최소 수집 정책을 정의한다.
- 스토어 약관, 자동화 금지 조항, 제휴 표기 의무를 검토해야 한다.

7. 실패/품절/대체상품 플로우
- 품절, 가격 변동, 검색 실패, 인증 만료 상황에서 대체 상품을 제안할 정책이 필요하다.
- 사용자가 승인하지 않은 자동 치환은 지양하고 확인 단계를 둔다.

8. 로그/분석/전환 트래킹
- 검색 진입, 상품 클릭, 장바구니 추가, 결제 전환을 추적할 이벤트 설계가 필요하다.
- 제휴 링크를 쓴다면 UTM/aff 파라미터 정책과 정산 구조도 함께 검토한다.
